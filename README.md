# Home Content Store

Simple home content store backend service for ingesting and streaming video content.

## Planned Scope

- [ ] v1: simple video streaming
- [ ] v1+: multiple resolution video streaming
- [ ] v2: video series streaming
- [ ] v3: music streaming

## Sample Movie

There is a sample movie in the `/sample` directory, which is `Popeye For President`. 
This film is in the public domain: https://publicdomainmovie.net/movie/popeye-for-president.
No copyright is broken by having this film available.
